CUNEUS

Data formats for glass, computed from the optics of the reader.

The lattice of dots written in the glass, the alphabet of each dot and the decoder are not drawn by hand: they are calculated from the microscope that will read them. In simulation, the dense layer reaches 51.9 bits/µm² before error correction with realistic writing errors, against 42.6 for its predecessor 4D-VODS under ideal assumptions.

Phase 1 of 6 done. Simulation only: nothing has been written in glass yet, and every number on this page is checked against the published results.

One plate, three readers

Each layer of the plate is written for a different reader, and each explains how to read the next one: a mark visible to the eye leads to plain text, the text explains a code for a cheap camera, and that code carries the index and format of the dense layer.

Why the hexagonal lattice stores more

A lattice of dots has a cell in frequency space that holds exactly one value per dot. The reader only sees the frequencies inside its pupil, a disc of radius NA/λ. Whatever part of the cell sticks out of the disc is never seen. A hexagon is closer to a disc than a square, so at the same density it loses less: at 265 nm, 6.1% of the square cell against 1.1% of the hexagonal one.

Phase 1: the decoder matters more than the lattice

Best information density before error correction, for both lattices at the same density, two decoders and three sets of conditions. With realistic errors the hexagonal lattice reaches 51.9 bits/µm²; cancelling the interference between neighbouring dots adds +24% in ideal conditions, more than the lattice itself (+11% with that decoder).

Show the numbers

  • The decoder matters most

    Interference cancellation subtracts the image of the decided neighbours and re-decides each dot: +24% on the hexagonal lattice in ideal conditions.

  • Hexagonal always wins, by less than first thought

    +10% with interference cancellation and +19% with the linear equaliser, averaged over four independent random seeds with realistic errors.

  • Learning the optics is free

    A decoder that learns the response from two frames of known symbols does as well as one that knows it exactly, because it uses the known pupil edge and a compact kernel.

  • Placement is the real limit

    Dots misplaced by 5% of the pitch cost about 20% of the density; the writer must hold about 6 nm to keep more than 90%.

  • Defocus becomes a slope

    Coherent defocus is a pure phase, so a decoder that re-learns the response at the actual focus keeps 49.7 bits/µm² one depth of focus away.

What limits it: where the dots land, and focus

Placement accuracy is the first thing to ask of any writer. Defocus is not a hard limit once the decoder learns the response at the focus it actually reads.

Go/no-go of Phase 1: conditional go

“Hexagonal gain of at least 15% over square, with a learnt response and placement errors of 5% of the pitch.”Criterion fixed in the concept note before the simulation was run.

Met with the linear equaliser, missed with interference cancellation. The hexagonal lattice stays the default because it wins in every condition, with both decoders and in every seed; the case for CUNEUS now rests on the decoder, the learnt response and the focus tolerance together. The +22% first estimated is withdrawn.

Every number can be rerun

The simulator, the results and this page live in one repository. Twelve validation checks compare the code with closed-form optics; every result file carries a hash, the command and the software versions that made it; every number quoted here is recomputed from the results on each push.

# exact reference environment (Python 3.13)
git clone https://github.com/GuettHM/cuneus && cd cuneus
pip install -r requirements-lock.txt
python -m cuneus validate        # physics checks -> docs/VALIDATION.md
python -m cuneus run all --quick # a small version of every experiment, about a minute
python -m cuneus run all --config configs/phase1.toml   # the published runs, about 25 min
python -m cuneus check           # every published number vs results/
pytest -q

Modelled

  • Scalar coherent imaging through a circular pupil, exact non-paraxial defocus
  • Dots of side 0.6 × pitch with 10% writing variability and sub-pixel placement errors
  • Detection noise of 64,000 photons per dot; periodic lattice with no edges
  • Decoders that learn the optical response from known symbols

Not modelled yet

  • Vectorial optics and three-dimensional dots at NA 0.90
  • Non-linear writing, camera pixels, aberrations other than defocus
  • A real error-correction code: densities are mutual information before correction
  • The human and low-cost layers (phases 4 to 5b)

CUNEUS by Hakim Guettal, 2026. I am not a professional physicist. CUNEUS grew out of my earlier study 4D-VODS, which started as a geometric intuition (storing data in the shape of engraved symbols); like it, this simulator and its documents were built with the help of AI tools on standard diffraction optics. Corrections from specialists are very welcome: please open an issue on GitHub.

AI assistants helped write the simulator, the documents and this page. Every result comes from the code in the repository and can be checked by re-running it.
